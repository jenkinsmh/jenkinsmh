## Current project: FairLair

**[FairLair](https://github.com/jenkinsmh/fairlair-project)** is a mobile app that helps households see the work that keeps a home running. That includes chores, errands, childcare and emotional care. Each family sets the balance it's aiming for, and the app shows how the actual work compares. The idea is to give families something concrete to talk about instead of arguing from memory.

I designed the concept and I'm building the app myself. It runs on iOS, Android and the web, built with Expo, React Native, TypeScript and Supabase. This term I'm adding household goals and running a pilot study with real families.

→ [Read more about FairLair](https://github.com/jenkinsmh/fairlair-project)
